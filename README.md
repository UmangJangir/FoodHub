
# OrderApp - Food Ordering System

A Python Flask based food ordering application.

## Technologies

- Python
- Flask
- SQLite
- HTML
- CSS
- JavaScript
- Razorpay

## User Roles

1. Customer
2. Admin
3. Delivery Person

## Payment Methods

- Cash on Delivery
- Online Payment

## Run Project

Activate virtual environment:

```bash
.venv\Scripts\Activate.ps1
```

Install dependencies:

```bash
python -m pip install -r requirements.txt
```

Start application:

```bash
python run.py
```

Open browser:

http://127.0.0.1:5000
